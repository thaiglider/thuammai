# ท่วมไหม (thuammai)

ประเมินความเสี่ยงน้ำท่วมรายพื้นที่ทั่วประเทศไทยจากข้อมูลเปิด อัปเดตทุก ~10 นาที

**เว็บไซต์:** https://thaiglider.github.io/thuammai/

> ข้อมูลประกอบการตัดสินใจเพื่อเตรียมพร้อม ไม่ใช่ประกาศทางการ — ทำตามประกาศของอำเภอ/เขตเสมอ
> เหตุฉุกเฉินโทร 1669 · 1784 (ปภ.) · 191

## แหล่งข้อมูล
สสน. (ThaiWater) · Longdo Traffic · Traffy Fondue · Open-Meteo (CC BY 4.0) · กรมอุตุนิยมวิทยา · ขอบเขตการปกครอง OCHA COD-AB (CC BY-IGO)

## การทำงาน
GitHub Actions (`.github/workflows/pipeline.yml`) ดึงข้อมูล ประเมินความเสี่ยง และเผยแพร่เป็นหน้าเว็บ + JSON ที่ `/data/` ผ่าน GitHub Pages
หมายเหตุ: GitHub ปิด schedule ของ repo ที่ไม่มีความเคลื่อนไหว 60 วัน — วงรอบหลักใช้ workflow_dispatch ต่อกันเอง
แอปหน้าแรกคำนวณความเสี่ยงในเบราว์เซอร์จากไฟล์ `/data/` ชุดเดียวกัน · หน้า `/p/` ใช้ได้โดยไม่มี JavaScript

## การเฝ้าระวังระบบ
- เว็บอัปเดตทุก ~10 นาทีด้วย workflow ที่สั่งรันตัวเองต่อกัน (workflow_dispatch) และมี schedule ทุก 15 นาทีเป็นตัวเฝ้า (watchdog) กรณีวงรอบขาด
- GitHub ปิด schedule อัตโนมัติเมื่อ repo ไม่มีความเคลื่อนไหว 60 วัน — ทุก commit ที่ปล่อย release นับเป็นความเคลื่อนไหว
- ตรวจว่าระบบยังทำงาน: เปิด https://thaiglider.github.io/thuammai/data/meta.json แล้วดูค่า `generatedAt` ควรไม่เก่ากว่า ~20 นาที
- ทุกหน้าแสดงเวลาของข้อมูลเป็นข้อความธรรมดา พร้อมคำเตือนว่าถ้าเก่ากว่า 1 ชั่วโมง ข้อมูลอาจไม่เป็นปัจจุบัน (ใช้ได้แม้ปิด JavaScript)
- ความแม่นย้อนหลัง: `.github/workflows/evaluate.yml` รันทุกวัน 06:00 น. เทียบระดับที่ประเมินกับรายงานน้ำท่วมและเซนเซอร์น้ำบนถนนในกรุงเทพฯ และปริมณฑล แล้วเก็บผลใน Release `archive-YYYY-MM` (`skill.json`, `tallies.json`, `archive-YYYY-MM-DD.json.gz`) — เว็บแสดงผลที่หน้าแหล่งข้อมูล และที่ `/data/skill.json` · ถ้ามี Release แล้วแต่ดึง `tallies.json` ไม่ได้ งานจะล้มเหลวโดยไม่อัปโหลดอะไร (เว็บคงผลเดิมไว้) — แก้โดยอัปโหลด `tallies.json` ที่ถูกต้องกลับเข้า Release ล่าสุด แล้วสั่งรันใหม่
- สั่งประเมินเองได้: Actions → evaluate → Run workflow (ถ้า evaluate ล้มเหลว เว็บยังอัปเดตตามปกติและใช้ผลครั้งก่อน)
